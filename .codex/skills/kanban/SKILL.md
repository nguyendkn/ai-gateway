# Kanban

Use this skill for task organization and status tracking.

## Workflow

1. Identify the project, plan, or task scope.
2. Group work into `Todo`, `In Progress`, `Blocked`, and `Done`.
3. Include owners only when known.
4. Link relevant files, plans, or validation evidence.
5. Update existing plan/checklist files only when requested or clearly expected.

## Rules

- Prefer existing `plans/` or docs structure.
- Do not create management overhead for tiny tasks.
- Use `project-manager` for larger progress audits.
