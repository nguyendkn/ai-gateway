# Content Writing

Use this skill for content creation or content improvement.

## Workflow

1. Identify audience, channel, offer, tone, and desired action.
2. Inspect product/docs context if needed.
3. Produce the strongest version plus 2-3 alternatives when useful.
4. Explain the angle briefly.
5. Suggest tests or variants for CRO work.

## Rules

- Use `copywriter` for conversion copy and `writer` for docs-style content.
- Avoid generic claims, unverifiable metrics, and corporate filler.
- Verify links when included.
- For CRO planning, use `plan-cro`.
