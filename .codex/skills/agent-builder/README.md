# codex-agent-template skill

Install project-scoped:

```bash
mkdir -p .agents/skills
cp -R codex-agent-template-skill .agents/skills/codex-agent-template
```

Install user-scoped:

```bash
mkdir -p ~/.agents/skills
cp -R codex-agent-template-skill ~/.agents/skills/codex-agent-template
```

Use in Codex:

```text
$codex-agent-template create a git-manager agent from this workflow...
```
