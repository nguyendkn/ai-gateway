# Brainstorm

Use this skill when the user wants divergent thinking before a decision.

## Workflow

1. Restate the decision or idea space.
2. Generate 3-6 materially different options.
3. Compare options on constraints, cost, risk, time, and reversibility.
4. Recommend one path only when the evidence supports it.
5. Hand off to `plan-two`, `plan-fast`, `plan-hard`, or direct execution if the user asks to proceed.

## Rules

- Keep ideas concrete enough to act on.
- Label assumptions and unknowns.
- Use `brainstormer`, `planner`, `architect`, or `dependency-expert` agents only when that materially improves the result.
- Do not implement during brainstorming unless the user explicitly switches to execution.
